# Data Dictionary - Personal Transactions Dataset

This document defines all columns in the personal_transactions.csv dataset used for the budgeting app.

---

## Table

| Column Name | Data Type | Description | Example |
|-------------|----------|-------------|---------|
| Date | DATE | Date the transaction occurred | 01/01/2018 |
| Description | TEXT | Description of payment | Thai Restaurant |
| Amount | NUMERIC(10, 2) | Cost of purchase | 1247.44 |
| Transaction Type | TEXT | What the transaction was made with | debit |
| Category | TEXT | Spending category assigned to transaction | Shopping |
| Account Name | TEXT | Name of account charged | Platinum Card |
